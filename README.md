# 📩 Spam Detection System

## 📌 Project Overview

The Spam Detection System is a machine learning-based application developed using Python. It detects spam messages and distinguishes them from legitimate messages using natural language processing and machine learning algorithms.

The project, **SpamGuard AI**, provides an interactive application for analyzing SMS and email messages, identifying suspicious content, and classifying messages as spam or not spam.

## 🎯 Project Objective

To develop an efficient and user-friendly system that automatically detects spam messages using machine learning techniques, helping users identify potentially harmful or unwanted messages.

## 🛠️ Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- SQLite
- TF-IDF Vectorization

## ✨ Key Features

- Detects spam and legitimate messages.
- Classifies SMS and email text.
- Uses Multinomial Naive Bayes and Logistic Regression algorithms.
- Applies TF-IDF for text feature extraction.
- Provides an interactive dashboard.
- Supports individual message scanning.
- Supports batch message analysis.
- Displays model performance metrics.
- Highlights suspicious keywords.
- Maintains prediction history.

## 🧠 Machine Learning Algorithms

1. **Multinomial Naive Bayes**
2. **Logistic Regression**

These algorithms are trained using TF-IDF features to classify messages into Spam and Not Spam categories.
